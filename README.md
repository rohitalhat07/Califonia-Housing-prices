
🏠 California Housing Price Prediction

📌 Project Overview

This project focuses on predicting median house values in California using Machine Learning. The California Housing dataset contains information about housing characteristics and demographic factors such as median income, house age, total rooms, population, households, latitude and longitude.

The project follows an end-to-end Machine Learning workflow, starting from data exploration and preprocessing to model training and evaluation.

🎯 Objectives

- Understand and analyze the California housing dataset
- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Identify relationships between housing features and house prices
- Build Machine Learning regression models
- Evaluate and compare model performance
- Predict median house values based on input features

📊 Dataset Features

The dataset contains the following features:

- "longitude"
- "latitude"
- "housing_median_age"
- "total_rooms"
- "total_bedrooms"
- "population"
- "households"
- "median_income"
- "median_house_value" — Target Variable

🔍 Exploratory Data Analysis

EDA was performed to understand the distribution and relationships between different housing features.

Key analysis includes:

- Statistical summary
- Missing value analysis
- Distribution analysis
- Correlation analysis
- Outlier analysis
- Feature relationship analysis
- Correlation heatmap
- Visualization of important housing features

🤖 Machine Learning

The problem is treated as a Supervised Learning Regression problem, where "median_house_value" is the target variable.

The project can be extended by comparing multiple regression algorithms such as:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting
- XGBoost

📏 Model Evaluation

Model performance is evaluated using:

- MAE — Mean Absolute Error
- MSE — Mean Squared Error
- RMSE — Root Mean Squared Error
- R² Score

These metrics help determine how accurately the models predict median house values.
